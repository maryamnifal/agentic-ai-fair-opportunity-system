How it works

Four agents work together.

The system separates evidence extraction, verification, compatibility, and ranking into individual agents.

A
Portfolio Evidence
Finds skills and supporting evidence from projects.
B
Skill Verification
Checks whether claimed skills are supported.
C
Job Compatibility
Compares the candidate against available roles.
D
Fair Ranking
Produces the final ranking using verified evidence.
Fairness principle
Verified evidence can support a candidate's ranking, while unsupported claims should not receive the same treatment.
